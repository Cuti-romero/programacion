El nombre del proyecto es: Formulario
en este formulario tenemos un inicio de seion, un registro si todavia no tenes cuenta, una recuperacion de contraseña y sistema de validacion.
Las tecnologias usadas para este proyecto fueron: html, css, javascript, vscode y ayuda de la IA (claude).
se ingresa al formulario de inicio de sesion. Completas los campos con los datos correctos e inicias. Si todavia no tenes una cuencta hecha, podes apretar el boton de Registro para poder crear una cuenta nueva, llenas todos los espacion y apretas el boton de registro. Para verificar que la cuenta exista, llega un mensaje con un codigo de 4 digitos para poder vefiricar tu usuario. Cuando los datos estan confrimados, te redirige a la pagina de inicio de sesion para poder completar los campos.
Si te olvidaste la contraseña, el link para reestablecer sirve. Apretas el link y te redirige a una pagina para poder poner tu mail, te llega un mensaje de un codigo con 4 digitos para poder verificar tu usuario, despues completas con la nueva contraseña y te redirige a la pagina de incio de sesion cuando ya esta tu contraseña lista.
